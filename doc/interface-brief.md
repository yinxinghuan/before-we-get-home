# 《回家之前》界面简报

- 玩家：使用手机或桌面浏览器的普通叙事游戏玩家，不需要 RPG 术语。
- 核心交互：看一张当前事件图，读一小段现场信息，在速度、援助与安全/资源之间选择。
- 情绪承诺：每次选择都让“回家”更近或让某个人更安全；压力明确，情绪不故弄玄虚。
- 主要状态：入口、决策、提交、行动结果、下一步、危险、人物对白、背包/世界、继续/重开、章节节点、真结局、加载/失败。
- 目标：手机竖屏优先，`320×568` 与 `390×844`；中间宽度与桌面响应式；触控、鼠标、键盘。
- 主要信息：当前地点和眼前发生什么；次要信息：三项数值与当前行动；支持信息：历史、人物、路线、背包、线索。
- 资产：4:5 入口与逐回合场景、1:1 英文海报、四名稳定人物、现代救援物品、统一 SVG 图标、参数化音频。
- 明确不做：长聊天记录、同屏罗列结果和选项、模拟经营仪表墙、末日废土视觉、多人信息墙。
