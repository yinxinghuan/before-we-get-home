# 《回家之前》领域规则实验记录

## 假设

若把一次性线索、有限电量、路线离开和角色入队从模型命令提升为本地原子事务，模型仍能自由叙事，但重复收益、数值漂移、越权人物与错误下一步会消失。

## 实验

- 事务 A：重听最后语音，只允许电量 `47 → 43` 并确认旧市场线索。
- 事务 B：与阿禾离站，只允许天亮前 `84 → 77`、当前位置进入 `old-market`、阿禾以稳定 ID 入队。
- 对抗输入同时尝试电量 / 时间 `+99`、伪造地图、提前加入周岚、重置 `station-exited` 和返回无关选项。
- 连续游玩覆盖成功、重复拒绝和未治理自由对话；另测旧存档错误预载及阿禾合法首次登场。

## 结果

机械测试最终状态保持电量 `43`、天亮前 `77`、地图 `old-market`、唯一同行者 `ahe-rider`；全部越权命令无效。390×844 浏览器流程可见“手机电量减少 4”、“天亮前 -7”、阿禾的有序登场和重复离站拒绝。

## 结论

对这类有有限资源但仍需开放叙事的现代灾难 RPG，最可靠的边界不是增加 prompt 禁令，而是让“是否合法、改哪些状态、下一步是什么”由本地裁判一次提交；模型只负责把已裁定结果写得自然。普通询问和情绪交流继续留在开放 AI 流程。
