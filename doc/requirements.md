# 《回家之前》需求文档

> 2026-08-12 改造实验：入口按钮必须是一次真实行动；首次行动产生可持久事实与明确资源后果。开场受管动作不得请求 AI，三种首选方法必须留下不同事实或数值轨迹；三项状态按玩家亲历逐步揭示。通过信号为一次点击得到首事实、受管链路零模型请求、刷新后事实与数值不丢失。

## 1. Overview

《回家之前 / Before We Get Home》是一款影像优先的现代灾难公路式 AI 角色扮演游戏：地震与暴雨切断城市，玩家作为一个没有特殊能力的普通人，必须在天亮和洪峰到来前穿过七个熟悉城区，依据家人的最后一条语音寻找母亲和弟弟；途中救下谁、相信谁、把有限电量和物资花在哪里，会改变路线、同伴和最后的团聚。

完整主线建议 `45–70` 个有效决策、约 `3–5` 小时，可跨多次存档；压缩试玩战役为 `28–36` 个关键决策并覆盖完整结局。游戏采用有明确终点的 guided 结构，但每个地区至少提供快速、稳妥和助人三种方法，不按固定对话轮数结束。

Game profile：单次打开通常投入 `8–20` 分钟，完成一个地点问题或确认一条家人线索后自然停下；跨次保留人物登场、同行关系、路线、背包、伤势、体力、天亮前时间、电量与已确认线索。首个有效动作是处理最后语音或离站，首局目标是离开中央车站，前 10 分钟建立“赶路 / 帮人 / 保资源”的真实取舍；回访理由是继续追踪家人，并承受上次路线承诺留下的后果。

## 2. Visual Design

- 沿用已经验证的 Civic 竖版影像优先布局：顶部仅保留体力、天亮前、手机电量三项状态；中部是一张覆盖主体区域的 4:5 场景图；当前对白、行动结果与选择严格按先后出现。
- 决策态字幕只承载新增局面、必要后果或人物对白；“请做出选择 / 接下来怎么做”和图片协议元数据不进入画面。选项本身已经充分说明动作时，字幕层应完全缺席。
- 世界采用当代灾后城市的纪录片式电影画面：雨夜蓝黑、钠灯橙、应急反光黄、湿沥青和真实生活物件；人物穿普通通勤、骑行或救援服装，不做末日废土、军事科幻或英雄海报。
- 开场不是前情提要卡，而是玩家亲历的 `6` 拍短序列：普通人抵达南广场 → 停电与余震发生 → 手机收到最后语音 → 母亲说出体育馆与河边警告 → 玩家确认时间和剩余电量 → 看见出口与需要帮助的骑手。前 `5` 拍隐藏选项和自由输入，第 `6` 拍才开放三个行动；第一张图不能提前画出玩家已经救人、找到同伴或抵达避难所。
- 每个成功回合生成一张 `512×640` 竖幅场景图。只有主角是主要可见人物并执行镜头主动作时复用用户头像参考图；同伴/NPC 主导、主角仅为陪衬/远景、环境和物品空镜均不传头像。
- 渲染提示必须为英文，路牌、手机、地图、病历、广播屏和纸面不得生成任何可读语言、汉字、字母、数字或伪文字；精确信息只在 UI 呈现。
- 游戏支持中英文；正式海报为 1024×1024，只允许英文标题 `BEFORE WE GET HOME`，禁止中文和伪文字。

## 3. Game Mechanics

### 3.1 开场与核心循环

- 时间为凌晨 `01:40`，地点为停电的中央车站。第一场余震刚结束，暴雨继续，官方预计洪峰在天亮前进入河湾低地。
- 母亲最后一条语音说她和玩家的弟弟小宇正去河滨体育馆，并提醒玩家“不要走河边”。消息发出后网络中断。
- 上述信息必须按玩家感知顺序出现，不能合并成“车站停电、家人失联、请做选择”的总结。每拍只增加一个可观察事实；玩家可以点字幕右侧的前进控件继续，但不能倒回循环，也不能用数字键提前触发尚未开放的选项。
- 核心循环：`抵达具体地点 → 读懂一项危险或人的需要 → 选择速度/安全/援助 → 消耗时间、电量、体力或物品 → 得到家人线索并打开下一条路线`。
- 同时最多存在 `3` 条线程：寻找家人的主目标、一个人物/救援支线、一个当前危险或路线问题。

### 3.2 三项常驻数值

| 数值 | 范围与初值 | 单回合最大变化 | 直接后果 |
|---|---:|---:|---|
| 体力 | `0–100`，初始 `82` | `22` | 低于 `30` 限制强行攀爬和负重；到 `0` 后在最近安全点醒来，增加伤势并损失时间，不删档。 |
| 天亮前 | `0–100`，初始 `84` | `18` | 低于 `28` 时洪水和封路升级；到 `0` 时家人会按自己的求生计划移动，玩家必须追踪新位置。 |
| 手机电量 | `0–100`，初始 `47` | `20` | 通话、地图、语音增强、手电和求救消耗；低于 `20` 出现警告，到 `0` 仍能前进，但失去导航、远程确认和部分结局证据。 |

食物、水、药物、绳索、雨衣和充电宝属于背包物品，不扩成第四条常驻数值。伤势、失温和烟雾吸入属于持久人物状态；同伴信任属于有来源的关系事件，可在人物详情查看。

### 3.3 城市路线与章节

1. **停电的中央车站（4–6 决策）**：理解最后语音、电量和三种行动意图；认识外卖骑手阿禾，决定是否结伴离站。
2. **旧市场的火（6–8 决策）**：电气火灾切断主路；玩家可协助疏散、从屋顶绕行或使用灭火器打开通道，并取得第一条家人线索。
3. **仁和医院（5–7 决策）**：医院缺电、走廊拥挤。玩家在查询伤员名单、帮忙运送药物和保持路线速度之间取舍；可获得急救包与护士周岚的可靠信息。
4. **积水隧道与高架桥（6–9 决策）**：快速隧道、危险断桥和漫长山路三条路线都可达，但各自需要不同物品、伙伴或代价。
5. **山坡社区（5–7 决策）**：玩家发现弟弟曾离开体育馆去找一名走散的同学；家人的“偏离计划”是一次具体救人行为，而非神秘阴谋。
6. **空体育馆（4–6 决策）**：体育馆已经二次转移。玩家从母亲留下的物品、志愿者证词和手机录音中拼出新目的地，并面对一次“先休息还是继续追”的关系选择。
7. **河湾学校屋顶（7–10 决策）**：洪峰前的最终营救。此前帮助过的人、保存的电量、同伴和路线事实都会提供真实能力，但没有任何一项是万能钥匙。
8. **天亮以后（3–5 决策）**：团聚、错过、留下救援或带着新同伴继续寻找等结果，由本地能力/代价清单和 AI 尾声共同生成。

### 3.4 人物连续性

- **母亲林岚，`lin-lan-mother`**：受过基础急救训练，保护弟弟并帮助邻居；只通过语音、目击和遗留物逐步确认位置。
- **弟弟小宇，`xiaoyu-brother`**：十六岁，因寻找走散同学而偏离体育馆；不能被写成无理由逃跑或等待营救的道具。
- **阿禾，`ahe-rider`**：十九岁的外卖骑手，熟悉小路，也在寻找姐姐；可成为稳定同伴，只有明确分开、受伤留守或完成个人目标才离队。
- **周岚，`zhoulan-nurse`**：仁和医院护士，掌握伤员与转移信息；她不能知道未经过医院的家人后续位置。
- AI 可以生成普通居民、志愿者、司机和小型救援事件，但不能替换上述人物 ID、制造第二位母亲/弟弟或让角色知道未获证实的信息。

### 3.5 背包、线索与电量

- 初始物品：手机、钥匙串、轻便背包、半瓶水。手机内保存“最后一条语音”，不可丢弃。
- 标志物“最后一条语音”可反复检查环境声、时间顺序和母亲语气；增强、分享、通话、地图和手电分别消耗 `4–12` 电量。
- 可获得物品包括充电宝、急救包、折叠雨衣、短绳、绝缘手套、纸质城市地图和母亲留下的红围巾。每件物品记录作用、限制、来源、数量和两项指标。
- 只有正文明确获得、接过、购买、装入或保留的物品才进入背包；看见和检查不等于拥有。消耗、交出、遗失或损坏必须同步移除。

### 3.6 危险与失败

- 普通探索 `2–4` 回合后才允许危险进入 `warning → confrontation → resolution`，结算后冷却至少 `2` 回合。
- 威胁包括余震、急流、电气火灾、烟雾、拥挤踩踏、黑暗中的碎玻璃与流浪动物，以及极少数因稀缺物资产生的人际冲突。
- 每次对峙提供三种实质不同的方法：用身体保护并强行通过、观察环境寻找安全路线、与同伴协作或消耗工具。物理战斗为 `rare`，不会把普通居民常态化为敌人。
- 五级 DC 为 `7 / 10 / 13 / 16 / 19`；固定 d20 由游戏、场景、遭遇周期和行动计算，刷新不重掷。
- 失败造成体力 `-14` 的默认代价，或由叙事合法替换为时间、电量、物品、路线关闭、伤势或伙伴分离；失败后必须恢复可操作状态和三个具体选择。

### 3.7 影像、声音与开放式结局

- 每个成功回合恰好生成一张当前事件图，不能继承中央车站、海报或上一地点构图；生成中保留上一张图，剧情状态先推进。
- 玩家镜头始终使用同一原始 1:1 头像 URL 与身份硬约束，最终 4:5 尺寸由媒体服务独立控制；环境空镜或其他人物单人镜头不强行加入玩家。
- 首次进入时，前两张玩家主导画面必须等待平台头像解析，宿主启动容忍窗口为 `10.5s`；已有存档中缺少当前身份版本的前两张玩家画面会在头像到达后自动重做一次，不要求清档。
- 终局先根据家人位置、时间、电量、伤势、阿禾关系、已帮助的人、仍持有的物品和履行/违背的承诺计算能力与代价，再允许 AI 写不同尾声。
- 至少提供 `8` 个质量锚点：一起回家、迟到的团聚、屋顶守夜、把路留给别人、没有信号的黎明、两家人的队伍、空房间的灯、继续寻找。锚点不是结局数量上限。

### 3.8 领域规则裁判与首次登场

- 模型负责描述城市如何回应玩家；本地 `domainRules` 负责稀缺数值、一次性线索、路线承诺和队伍变更是否合法。命中规则的整回合只执行一个本地事务，模型输出的数值、事实、地图、人物、危险和下一组选项全部丢弃。
- 开场“重听语音”固定结算为手机电量 `-4` 和 `voice-old-market-clue=true`，只发生一次；重复尝试不再扣电，也不生成第二条线索。
- “帮助 / 请橙色雨衣骑手带路”固定结算为天亮前 `-7`、当前位置 `old-market`、`station-exited=true`，并让稳定角色 `ahe-rider` 加入。重复离站不重复消耗或奖励；拒绝回合不推进危险节拍。
- 阿禾、周岚在真实登场前不进入人物面板、关系、队伍或行动选项。阿禾首次登场必须先显示橙色雨衣与扶车动作，再由她自报姓名，说明寻找姐姐和带路意图，最后才允许互动并写入存档。家人林岚和小宇是玩家开场前已认识的人，可从初始人物表保留。

## 4. Controls

- 第 `0` 场字幕使用单向分页：点击至少 `44×44 CSS px` 的前进控件依次经历 `6` 拍；到最后一拍后控件消失，三个选择和自由输入同步出现。
- 普通行动按钮单击一次立即提交；同一时间只显示当前可选行动，不需要再点输入框后的提交。
- 结果阶段隐藏旧字幕和下一组选项；点击“查看下一步选择”后结果收起，新决策前提与三个选项同步出现。
- 自由行动、求救留言和需要玩家自己写内容时才展开输入框；Enter 或发送按钮提交。
- 世界/状态面板可查看人物、地图、背包、伤势、线索和日志；返回玩家可选择继续或确认重新开始。
- 键盘支持数字键 `1–3` 选择行动、`W` 打开世界、`H` 打开历史、`Escape` 关闭顶层面板。
- 触控目标至少 `44×44 CSS px`；支持 `320×568`、`390×844`、`1024×768`、`1440×900`，桌面端使用居中宽画幅而非拉伸手机壳。

## 5. Win / Lose Conditions

- 真结局在玩家抵达河湾学校屋顶并明确完成最后一次营救/去留决定后触发；章节节点、休息和区域转移都可继续，不算结束。
- “找到家人”有多种真实状态：在屋顶团聚、追上二次转移、受伤后被家人反向找到、确认家人安全而留下救援，或因时间/路线失去当晚会合但获得可继续寻找的可靠地点。
- 体力、时间或电量归零都不删除存档。体力归零使玩家在安全点醒来；时间归零推进洪峰和家人位置；电量归零关闭数字能力。
- 结局必须包含一个具体被保住的人或承诺、一个不可撤销的代价、至少三名人物的去向、一项来自沿途选择的回响，以及天亮后仍要面对的问题。
- 同一终局快照刷新不重抽。玩家可继续尾声，或从确认框选择只重置本游戏的“重新开始”。

## 6. Sound Effects

- 使用参数化 Web Audio；首次玩家手势后解锁，后台暂停，静音记忆，音频失败不阻塞游戏。
- 基础声景 `62 BPM`：低音雨点 `55–75 Hz`、远处电力嗡鸣 `95–120 Hz`、稀疏心跳脉冲 `48/62 Hz`；避难所加入 `220–330 Hz` 的温暖木质泛音。
- 普通行动：`90 ms` 干燥按钮声；路线确认：`0→7` 半音、`240 ms`；线索确认：三段 `0→4→7`、`360 ms`；手机耗电：`520→390 Hz` 下落、`180 ms`。
- 危险警告：两次 `76 Hz` 脉冲、间隔 `140 ms`；受伤：`65 Hz` 噪声冲击、`220 ms`；家人信号恢复：`0→5→9→12`、`620 ms`，只在重要节点使用。
- 每回合只突出一个最高等级声音事件；减少动态或静音时以颜色、图标、文字和状态变化完整表达结果。
